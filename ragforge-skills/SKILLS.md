# RAG Skills

Framework-agnostic RAG development skills for coding agents. Works with any RAG project — LangChain, LlamaIndex, custom stack, or ragforge.

| Skill | Description | Invoke When |
|---|---|---|
| `rag-workflow` | Full RAG lifecycle, phase sequencing, component selection | Starting a project or unsure of next step |
| `rag-ingestion` | Loaders, chunking strategies, embedding models, vector stores | Configuring data ingestion |
| `rag-retrieval` | Dense / hybrid / reranker decision logic, k selection | Choosing or tuning retrieval |
| `rag-eval` | Metrics, thresholds, evalset construction, CI gate | Setting up or debugging evaluation |
| `rag-observe` | 4-layer instrumentation, Langfuse, OTLP, Arize Phoenix | Adding telemetry or debugging regressions |
| `rag-deploy` | Docker, IaC, cloud targets, env config | Containerizing or deploying |
